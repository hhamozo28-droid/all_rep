# Generator source export

This archive contains the source project for the course-generation pipeline.

- `pipeline/`: working source tree, scripts, JSON subject data, knowledge bases, Mermaid source flows, fonts, and source diagram assets.
- `scripts/`: convenience copies of the top-level Python and shell scripts from `pipeline/`.
- `specs/`: convenience copy of `pipeline/spec_kb/` JSON specs.
- `data_json/`: source inventories and metadata JSONs from `uploads/new_specialty/`.
- `skills/`: generator skill notes and the shared Arabic font library.

Final PDF/DOCX deliverables and runtime caches are intentionally omitted. The runtime API token file `.gemini_token` is also excluded for security.

Main overview: `pipeline/README.md`.
