# خط أنابيب توليد المذكرات ومخططات الدروس — دليل التخصص الجديد

هذا المجلد يحتوي كل أدوات التوليد جاهزة لاستقبال **تخصص جديد**.
المخرجات (Word + PDF) تُكتب تلقائياً في مجلدات المواد بجذر مساحة العمل `/home/user/`.

## الحزم المطلوبة (تُثبَّت في كل جلسة جديدة)
```bash
pip3 install pymupdf reportlab arabic-reshaper python-bidi matplotlib pillow python-docx
```

## خطوات العمل عند وصول التخصص الجديد

### 1) استقبال المخططات/البرامج (PDF)
ضع ملفات التخصص في `/home/user/uploads/` ثم استخرج نصوصها:
```bash
python3 -c "
import pymupdf, glob, os
for f in glob.glob('/home/user/uploads/*.pdf'):
    doc = pymupdf.open(f)
    open('/home/user/pipeline/extract_' + os.path.basename(f)[:-4] + '.txt', 'w').write(
        '\n'.join(p.get_text() for p in doc))
    print(os.path.basename(f), len(doc), 'pages')"
```

### 2) بناء ملفات المحتوى
انسخ `content_template.py` إلى ملف جديد لكل مادة (مثال: `content_m9.py`)
املأ لكل درس: العنوان (عربي/فرنسي)، الساعات (th نظري / tph تطبيقي)، الهدف، الوضعية،
المحتوى النظري theory (كتل: h2 عنوان قسم، p فقرة، b نقطة، n خطوة مرقمة، t جدول، note ملاحظة، img صورة)،
أنشطة tp، التقييم evaluation، الخلاصة، الواجب، المصطلحات glossary.

### 3) توليد المخططات (Plans de leçon — النموذج الرسمي M9-1)
- الصيغة: بطاقة درس ثنائية اللغة + جدول سيرورة التكوين (10 أعمدة) + تمارين + رسومات — Landscape ألوان زاهية
- أضف مادة التخصص إلى قائمة SUBJECTS في `run_plans.py`
- المخططات: `python3 run_plans.py CODE` (أو بدون معاملات للكل)
- **قبل ذلك**: ولّد الرسوم البيانية بـ `make_plan_diagrams.py` (أضف رسوم المواد الجديدة بنفس الطريقة)
  وسجّل خريطة الصور LESSON_IMGS في `run_plans.py`

### 4) توليد المذكرات (اختياري — مذكرة بيداغوجية لكل درس)
- أضف المادة إلى `run_all.py` ثم: `python3 run_all.py CODE`
- تُنتج: غلاف + فهرس + مذكرة لكل درس (10 أقسام) — Word + PDF

## الملفات الأساسية
| الملف | الدور |
|---|---|
| `plan_lib.py` | مكتبة عرض مخططات الدرس (DOCX + PDF، خطوط Amiri/Tajawal، ألوان زاهية) |
| `run_plans.py` | مولّد المخططات: يحوّل المحتوى إلى بطاقات + جداول + تمارين + رسومات |
| `make_plan_diagrams.py` | مولّد الرسوم البيانية (matplotlib بألوان زاهية) |
| `memo_lib.py` + `generate_all.py` + `run_all.py` | خط توليد المذكرات البيداغوجية |
| `content_template.py` | قالب بنية محتوى الدرس (انسخه واملأه) |
| `plan_fonts/` | خطوط Amiri + Tajawal للـ PDF |
| `plan_images/` | الرسوم البيانية المولّدة (تُضمَّن في المخرجات) |
