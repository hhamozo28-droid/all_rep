## المرحلة 1 — اختيار التمرين المناسب

المخطط التدفقي يخدم **تمرينًا ذا مسار قرار**، لا تمرين تعريف. معايير الترتيب：

| الأولوية | نوع التمرين | لماذا |
|---|---|---|
| 1 | تمرين فيه **شرط/قرار** (هل…؟ نعم/لا) | يُظهر المعين والمسارين |
| 2 | تمرين **حسابي/إجرائي** متعدد الخطوات | يُظهر المستطيلات والمتوازيات |
| 3 | تمرين تصنيف/مقارنة | يُظهر تفرعًا بسيطًا |

**قاعدة:** يُختار **تمرين واحد لكل طلب**، ويُوسَّع نصه ليصبح حالة عملية (معطيات رقمية + قرار مطلوب) بدل سؤال جاف من سطر واحد.

## المرحلة 2 — تحليل التمرين واستخراج المخطط (Flowchart Extraction)

يُستخرج بالترتيب ستة عناصر، وتُكتب في جدول تحليل قبل أي كود：

| العنصر | الرمز في Mermaid | ماذا يُكتب فيه |
|---|---|---|
| البداية | `([بداية])` | نقطة الانطلاق |
| المدخلات | `[/…/]` متوازي الأضلاع | المعطيات الرقمية/الوثائق |
| العمليات | `[ … ]` مستطيل | الحساب، الترميز، التجميع، المقارنة |
| الشروط | `{ … }` معين | سؤال ثنائي واضح (نعم/لا) |
| المخرجات | `[/…/]` | التقرير/القرار/الوثيقة |
| النهاية | `([نهاية])` | إغلاق المسار |

**قواعد صياغة العُقد：**
- عقدة واحدة = فكرة واحدة، ≤ 6 كلمات عربية.
- الشرط يُكتب سؤالًا قابلًا للإجابة بنعم/لا فقط.
- كل مسار يجب أن ينتهي إلى **المخرج نفسه** أو إلى عقدة إغلاق.
- لا تضع اسم الدليل/رقم الصفحة داخل العقد.

<قائمة: النوع | النص | ملاحظة>

[3] الشروط والمسارات
<الشرط 1> → نعم: <عقدة> | لا: <عقدة>
<الشرط 2> → نعم: <عقدة> | لا: <عقدة>

[4] المواصفات التقنية الإلزامية

  "lineColor":"#B5733A","tertiaryColor":"#FCF0E4"},

- النص في العُقد ≤ 6 كلمات لكل عقدة.

[5] المخرجات المطلوبة
1) كود Mermaid كاملًا داخل code block واحد.
2) جدول تحليل: العنصر / العقدة / الدور المنطقي.
3) تحذيرات: أي عقدة قد تسبب تقاطعًا بصريًا، ومقترح الإصلاح.

## المرحلة 5 — الإدراج الذكي داخل الدليل

1. خزّن المخطط في `content.json` بمفتاح مستقل **لا يغيّر بنية التمارين**：
   ```json

     "ch6_ex16": {"file":"flow16.png","caption":"…","mermaid":"…"}
   }
   ```
2. في `build.py`： داخل حلقة التمارين، وبعد «المطلوب» وقبل «مساحة العمل»：
   ```python
   fc = DATA.get('flowcharts', {}).get(f'ch{i+1}_ex{local_idx}')
   if fc: br()                    # ابدأ صفحة جديدة للتمرين كي لا ينفصل عن مخططه
   ...
   if fc:
       para('**المخطط التدفقي للحل (اختر مسارك على المخطط قبل الكتابة):**', size=13)
       pic(GFX/fc['file'], 8.2, fc['caption'])   # 7.8–8.4 سم
   ```
3. أضف فقرة سياقية في **قسم نظري** مناسب تشرح قراءة المخطط («يُترجم كل قرار إلى مسار: مدخلات ← معالجة ← شرط حاسم ← مسارا القرار»).

## ملحق تنفيذي (مُحدَّث بعد تطبيق شامل على دليل MQ1.1)

### ما طُبِّق فعليًا: 25 مخططًا في دليل واحد
| الموضع | العدد | المفردات |
|---|---|---|
| أقسام نظرية (بعد كل قسم) | 6 | أنواع الدراسة، مراحل البحث، مصادر المعلومة، المسح البيئي، الدراسة النوعية، من العينة إلى القرار |
| تمارين | 12 | كل تمرين فيه شرط/مسار حسابي |
| دراسات حالة | 6 | واحدة لكل حالة (لا استثناء) |
| ملاحق | 1 | خطة عشرة أيام |
| تمرين المخطط القديم | 1 | تمرين 106 (بصيغة خاصة) |

### قواعد إلزامية مستخلصة من التجربة
1. **لكل موضع مخططه الخاص**: لا تُكرَّر صورة في فصلين؛ كل `key` له ملف `.mmd` و`.png` مستقل.
2. **الاختيار آليًا وليس يدويًا**: خزّن خريطة `SEC_FLOWS` و`EX_FLOWS` و`CASE_FLOWS` في `build.py`؛ يُحقن المخطط تلقائيًا في الموضع الصحيح دون تعديل المحتوى.
3. **فحص النسبة شرطٌ للقبول**: `ratio = h/w`. إن خرج `> 2.4` أو العرض `< 700px`، أعد الرسم بـ`RL` (اتجاه عربي) مع `-s 2` أو `-s 3`، وقارن النتيجتين واختر الأفضل.
4. **ارتفاع المخطط محسوب**: العرض في Word = `min(cap, 13.4/ratio)` حتى لا يتجاوز ارتفاع الصورة 13.4 سم (حدّ الصفحة المتاح).
5. **الأسطر المنقطة تُخفَّض**: بعد إدراج مخطط في تمرين، خفّض أسطر العمل من 8 إلى 3–5، وإلا ظهرت صفحة شبه فارغة.
6. **الحالات ذات المخططات**: لا تُضف «معالم المعالجة» + 9 أسطر بعد المخطط؛ المخطط نفسه هو مساحة العمل.
7. **صفحة شبه فارغة = خطأ**: افحص بعد التصدير كل صفحة طول نصها < 260 حرفًا، وأصلح الموضع بالتقليل أو بالإدراج في موضع آخر.
8. **التتابع البرمجي**: `flows.json` (المصدر) ← `render_flows.py` (الرسم والفحص) ← `gfx/*.png` ← `build.py` (الإدراج). لا تعدّل الصور مباشرة.

### مخططات موصى بها لكل نوع محتوى
| نوع المحتوى | المخطط المناسب |
|---|---|
| خطوات أو مراحل متتابعة | `flowchart TD` بلا شروط (مستطيلات متسلسلة) |
| قرار أو تصنيف | معين + مساران موصوفان «نعم/لا» |
| خريطة مصادر | نجمة: مركز + أطراف بأسهم داخلة وخارجة |
| حلقة تحسين/تكرار | سهم راجع إلى عقدة سابقة (حلقة) |
| أخطاء ومعالجات | فرع «فشل» يعود إلى خطوة سابقة |
| مقارنة معايير | خيارات فروع من معين واحد (لا شروط متداخلة) |
