# ملفات الدروس — رابط مباشر

ارفع هنا ملفات الدروس المولّدة (PDF / Word). الملفات في هذا المجلد تُخدَم مباشرة على نطاق المنصة، ويمكن نسخ رابطها وإضافته إلى روابط التخصص في لوحة الإدارة.

## رابط الرفع
https://github.com/hhamozo28-droid/all_rep/upload/main?path=public/lessons

المستودع: https://github.com/hhamozo28-droid/all_rep — الفرع: `main`

## رابط التحميل المباشر
بعد رفع الملف على `main` (ينتظر النشر التلقائي على Vercel دقائق):

```
https://allrep-theta.vercel.app/lessons/اسم-الملف.pdf
```

أو فوراً من GitHub بدون انتظار النشر:

```
https://raw.githubusercontent.com/hhamozo28-droid/all_rep/main/public/lessons/اسم-الملف.pdf
```

## تفضيلات التسمية
استخدم أسماء لاتينية بدون مسافات أو رموز خاصة، مثال: `MES0701-lecon01.pdf`.
إن احتوى الاسم مسافات أو أحرف عربية، انسخ الرابط من شريط المتصفح بعد فتح الملف (سيكون مُرمّزاً تلقائياً).

## الاستخدام
ضع **رابط التحميل المباشر** في حقل رابط الدرس داخل التخصص من لوحة الإدارة. عند ضغط الرابط من التطبيق أو الموقع يُحمّل الملف مباشرة (بدون صفحة مشاركة مثل gofile).
